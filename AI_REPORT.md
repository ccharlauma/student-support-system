# AI Usage Report

## Project
StudentHub Support Center – Student Support & Ticket Management System

## AI Assistance

AI tools were used during the development process to support understanding, implementation, debugging, and documentation.

### Areas Where AI Was Used

- Understanding project requirements and functionality.
- Getting guidance for frontend HTML, CSS, and JavaScript implementation.
- Getting assistance with FastAPI backend structure and API implementation.
- Understanding database integration using SQLAlchemy and SQLite.
- Debugging coding errors and improving implementation.
- Improving the user interface and layout.
- Preparing project documentation such as the README and approach note.
- Reviewing the implemented functionality and suggesting improvements.

## Human Contribution

The project was implemented, tested, and reviewed by the developer. The developer made the final decisions regarding the project structure, functionality, UI, code changes, testing, and submission.

## Testing

The implemented features were tested manually, including:

- Creating support tickets
- Viewing support tickets
- Searching tickets
- Filtering tickets by status
- Updating ticket status
- Deleting tickets
- Tracking ticket priority
- Dashboard statistics
- Frontend-backend communication

All major implemented functionalities were tested successfully.

## Conclusion

AI was used as a development assistance tool for guidance, debugging, learning, and documentation. The final project was reviewed and tested by the developer before submission.
