# StudentHub Support Center

A Student Support & Ticket Management System that allows students to submit support requests and administrators to manage, track, and update support tickets through a simple web-based dashboard.

## Features

- Create student support tickets
- View all support tickets
- Search tickets
- Filter tickets by status
- Track ticket status
- Set ticket priority
- Update ticket status
- Delete tickets
- Dashboard with ticket statistics
- Responsive and professional user interface

## Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- FastAPI
- SQLite
- SQLAlchemy
